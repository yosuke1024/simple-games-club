# web/

The Simple Games web build goes here (`index.html` and `assets/`), so this
server can hand out invite links that open straight into the games
(`/join#invite=…`). It is a release artifact of the
[simple-games](https://github.com/yosuke1024/simple-games) repository, not
source — see the top-level README, "Web build".

Without it the server still runs: `/` and `/join` show a one-line notice and
the API is fully usable.
